# 🍽️ Angara Restro

Angara Restro is a modern and responsive restaurant website designed to showcase delicious food items, menu categories, and gallery images with a clean user interface.

## ✨ Features

- Responsive design for mobile and desktop
- Category-based menu filter buttons
- Vertical menu cards with item descriptions
- Food gallery section with all images
- Smooth and modern UI design
- Easy navigation and clean layout

## 🍜 Menu Highlights

- Plain Maggie
- Masala Maggie
- Beverages
- Main Course
- Rice & Breads
- Starters

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React
- Tailwind CSS
- Vite

## 📸 Gallery

All food and restaurant images are available in the “Gallery View” folder.
